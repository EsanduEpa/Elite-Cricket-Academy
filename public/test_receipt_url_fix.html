🔍 Medical Receipt URL Test

Problem Explanation

Issue: Clicking "View" button redirects to login page

Cause: Incorrect URL construction for receipt files

❌ Incorrect URL (Before Fix)

http://localhost/Elite/public/uploads/medical_receipts/receipt_1_1729603200.jpg

🔴 This URL is treated as an application route, which doesn't exist, causing redirect to login.

✅ Correct URL (After Fix)

http://localhost/Elite/uploads/medical_receipts/receipt_1_1729603200.jpg

🟢 This URL correctly points to the file in the public directory.

What Was Changed

  1. Controller (Player.php):
    • Changed: $diagnosisReceiptURL = $targetPath;
    • To: $diagnosisReceiptURL = 'uploads/medical_receipts/' . $fileName;
    • Effect: Stores path without 'public/' prefix
  2. Views (medical.php, injury-reports.php, health.php):
    • Added: $receiptPath = str_replace('public/', '', $record->DiagnosisReceiptURL);
    • Effect: Removes 'public/' prefix if it exists (handles old records)
  3. Database:
    • Run: fix_receipt_urls.sql
    • Effect: Updates existing records to remove 'public/' prefix

Testing Steps

  1. Run the database fix script: 
    mysql -u root -p cricket_academy < fix_receipt_urls.sql
  2. Upload a new medical receipt via Player → Medical → Add Record
  3. Check the database to verify path is stored as: uploads/medical_receipts/filename.ext
  4. Click "View" button in the medical records table
  5. File should open in new tab without redirect to login

Why This Works

The public folder is the web root of the application. Files inside it can be accessed directly via URL:

  • File location on server: C:\xampp\htdocs\Elite\public\uploads\medical_receipts\file.jpg
  • Web URL: http://localhost/Elite/uploads/medical_receipts/file.jpg

The public/ part is implicit in the URL because public is the document root.

  • ✅ Views handle both old and new path formats
  • ✅ Database migration script provided
  • ✅ No errors in any modified files
  • ✅ Backwards compatible with existing data
